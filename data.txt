人工智能（Artificial Intelligence，AI）是计算机科学的一个分支，旨在创建能够执行通常需要人类智能的任务的系统。AI 系统可以学习、推理、感知环境并做出决策。

机器学习是人工智能的一个子领域，它使计算机能够从数据中学习，而无需明确编程。通过分析大量数据，机器学习算法可以识别模式并做出预测或决策。

深度学习是机器学习的一个子集，它使用神经网络来模拟人脑的工作方式。深度学习在图像识别、自然语言处理和语音识别等领域取得了突破性进展。

自然语言处理（NLP）是人工智能的一个分支，专注于计算机与人类语言之间的交互。NLP 技术使计算机能够理解、解释和生成人类语言。

计算机视觉是人工智能的一个领域，使机器能够解释和理解视觉信息。计算机视觉系统可以识别图像和视频中的对象、人脸和场景。

强化学习是一种机器学习方法，其中智能体通过与环境交互来学习最优行为。智能体通过试错和奖励机制来改进其行为策略。

神经网络是受生物神经网络启发的计算模型，由相互连接的节点（神经元）组成。神经网络可以学习复杂的模式，并在各种任务中表现出色。

大数据是指传统数据处理软件无法有效处理的庞大而复杂的数据集。大数据技术使组织能够存储、处理和分析大量数据以获得有价值的见解。

云计算是通过互联网提供计算服务（包括服务器、存储、数据库、网络、软件）的模型。云计算提供了按需访问计算资源的灵活性。

容器化是一种操作系统级虚拟化方法，用于部署和运行分布式应用程序。容器将应用程序及其依赖项打包在一起，确保在不同环境中一致运行。

DevOps 是开发和运维的结合，旨在缩短开发生命周期并提供高质量的持续交付。DevOps 实践强调自动化、协作和持续改进。

CI/CD（持续集成/持续部署）是一种软件开发实践，允许团队频繁地将代码更改集成到共享存储库中。CI/CD 自动化了构建、测试和部署过程。

微服务架构是一种将应用程序构建为小型、独立服务集合的方法。每个微服务都可以独立开发、部署和扩展。

API（应用程序编程接口）是一组定义和协议，用于构建和集成应用程序软件。API 允许不同的软件组件相互通信。

REST（表述性状态传递）是一种用于设计网络应用程序的架构风格。RESTful API 使用 HTTP 方法（GET、POST、PUT、DELETE）来操作资源。

Docker 是一个用于开发、部署和运行应用程序的开源容器化平台。Docker 容器提供了一种轻量级、可移植的方式来打包和运行应用程序。

Kubernetes 是一个用于自动化容器化应用程序的部署、扩展和管理的开源系统。Kubernetes 提供了容器编排、服务发现和负载均衡等功能。

AWS（Amazon Web Services）是亚马逊提供的云计算平台。AWS 提供广泛的计算、存储、数据库、网络和分析服务。

Terraform 是一个用于构建、更改和版本控制基础设施的开源工具。Terraform 使用声明式配置来管理云基础设施。

Git 是一个分布式版本控制系统，用于跟踪源代码更改。Git 允许开发人员协作开发项目，并维护代码的完整历史记录。

GitHub Actions 是 GitHub 提供的持续集成和持续部署（CI/CD）平台。它允许开发人员自动化软件开发工作流程。

AWS App Runner 是一项完全托管的服务，可以轻松地从源代码或容器镜像快速部署 Web 应用程序和 API。App Runner 自动处理构建、部署和扩展。

Amazon ECR（Elastic Container Registry）是 AWS 提供的完全托管的 Docker 容器注册表。ECR 使开发人员可以轻松存储、管理和部署 Docker 容器镜像。

AWS Secrets Manager 是一项服务，可帮助您保护访问应用程序、服务和 IT 资源所需的密钥。Secrets Manager 使您能够在整个生命周期中轻松轮换、管理和检索数据库凭据、API 密钥和其他密钥。

OIDC（OpenID Connect）是基于 OAuth 2.0 协议的身份层。OIDC 允许客户端验证最终用户的身份，并获取有关用户的基本配置文件信息。

IAM（Identity and Access Management）是 AWS 提供的服务，用于安全地控制对 AWS 服务的访问。IAM 允许您管理用户、组、角色和权限。

RAG（Retrieval-Augmented Generation）是一种结合了信息检索和文本生成的技术。RAG 系统首先从知识库中检索相关信息，然后使用这些信息生成更准确和相关的回答。

LangChain 是一个用于构建基于语言模型的应用程序的框架。LangChain 提供了用于连接语言模型与数据源和工具的工具和抽象。

向量数据库是一种专门用于存储和查询高维向量的数据库。向量数据库在相似性搜索和推荐系统等应用中非常有用。

FAISS（Facebook AI Similarity Search）是 Facebook 开发的一个库，用于高效相似性搜索和密集向量聚类。FAISS 可以处理数百万甚至数十亿个向量。
